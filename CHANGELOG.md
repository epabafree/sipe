# Changelog

## v0.16.0

Added CAT 2018 Slot 1: 86 questions (21 VARC, 32 DILR, 33 QA) and 11 set cards (3 RC passages, 8 DILR sets), numbered as in the exam.

- DILR Set 5: the monthly and quarterly LED sales are laid out as a table, 2016 beside 2017.
- DILR Set 4: the set solution lists all six possible pump patterns in one table.
- DILR Set 8: the solution table shows the composite scores of the six candidates who decide the recruitment.

## v0.15.0

## v0.5.0

Added CAT 2022 Slot 1: 66 questions and 8 set cards. VARC and DILR follow the exam order; seven QA questions (2, 3, 12, 13, 14, 19 and 21) are numbered approximately.

The deck layout has changed. Top-level decks are numbered and use full section names, set cards sit under their section, and each paper card has its own deck under `06 Papers & Mocks`. Existing installs need a fresh import; see [docs/updating.md](docs/updating.md).

Added topic-wise practice (`04 Practice by Topic`). Questions from all papers are grouped by topic area, with filters for subtopic and paper.

Other changes:
- Removed the flag reminder from the answer side.
- Paper and topic cards show the same content on both sides.
- Four new formula cards: three-set overlaps, absolute values as distances, the greatest integer function, distributing identical objects.
