# Install on iPad or iPhone

There are two routes.

## AnkiMobile (official app, paid once)
AnkiMobile is the official Anki app for iOS. It's a one-time purchase on the App Store and supports everything in this deck.

1. Install **AnkiMobile Flashcards** from the App Store.
2. Download `sipe.apkg` from the latest release on **Releases**, tap it, and choose **Open in AnkiMobile**. Or use the Files app's share sheet.
3. Open **sipe ▸ 00 Start Here**.

## Free route: AnkiWeb in Safari
1. Import the deck with Anki on a computer (or AnkiDroid) and **sync** it to a free **ankiweb.net** account.
2. On the iPad, open **ankiweb.net** in Safari, sign in, and study.

> AnkiWeb is designed for quick reviews. How well the interactive parts of these cards (tapping options, toolbar, mock) behave there is being tested; the results will be written up here. If something doesn't work, use AnkiMobile or a computer for full features.
