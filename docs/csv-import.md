# CSV import

Each release also includes the deck as CSV files with a `media/` folder, if you'd rather import that way.

1. Import `sipe.apkg` once so the note types exist.
2. Copy the contents of `media/` into your profile's `collection.media` folder.
3. Import each CSV with File ▸ Import. Deck, note type, tags and IDs are set in the file headers, and re-importing updates existing notes.

| File | Contents |
| --- | --- |
| `sipe_questions_VARC.csv`, `_DILR`, `_QA` | Question cards |
| `sipe_sets.csv` | Set cards |
| `sipe_formulas_techniques.csv` | Formula and technique cards |
| `sipe_topic_practice.csv` | Topic practice cards |
| `sipe_mock.csv` | Paper cards |
| `sipe_start_here_*.csv` | Guide and Study Planner |
