# Flags

The deck uses four of Anki's flag colours. They're optional, and the Study Planner can filter by them.

| Flag | Meaning | Desktop |
| --- | --- | --- |
| Red | Didn't know the concept | Ctrl/⌘ + 1 |
| Orange | Careless mistake | Ctrl/⌘ + 2 |
| Blue | Right, but too slow | Ctrl/⌘ + 4 |
| Green | Learnt a new trick | Ctrl/⌘ + 3 |

On a phone, use the flag button in the review menu. Press the same shortcut again to clear a flag.
