# Installing on Android

1. Install AnkiDroid from Google Play (it's also on F-Droid).
2. Download `sipe.apkg` from the [latest release](https://github.com/epabafree/sipe/releases/latest).
3. Open the file with AnkiDroid, or use ⋮ ▸ Import.

Long-press an option to cross it out. If AnkiDroid's night mode inverts the card colours, turn off colour inversion in its settings and use the theme switch on the card instead.
