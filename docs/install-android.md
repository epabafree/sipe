# Install on Android (free)

1. Install **AnkiDroid** from the Google Play Store. It's free and open source; it's also on F-Droid and its GitHub releases page.
2. Download the latest `sipe_….apkg` from this repository's **Releases** page to your phone.
3. Open the file and choose **AnkiDroid**, or in AnkiDroid tap **⋮ ▸ Import** and pick the file.
4. Open **sipe ▸ 00 Start Here**.

**Tips**
- Long-press an option to cross it out.
- The flag button in the review screen's menu sets the four [mistake flags](flags.md).
- If you also use Anki on a computer, sync both with a free AnkiWeb account (AnkiDroid ▸ Sync).
- If AnkiDroid's own night mode inverts colours oddly, turn colour inversion off in its settings and use the card's own theme switch instead.
